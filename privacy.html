プライバシーポリシー

対象: Codex Drive Workspace（個人用）。この接続は、Google Driveの所有者本人の指示によるクラウド作業に使用します。

アクセスするデータと利用目的

許可されたGoogle Driveのファイル名、識別子、フォルダ、更新日時などのメタデータ、および指示されたファイルの内容を扱います。検索、読取、分析、成果物の作成・保存・編集に使用します。

処理先と保管

指示されたデータはGoogle DriveとOpenAIのChatGPT Work・Codex Cloudで処理され、作業履歴や成果物としてそれぞれのサービスに保管される場合があります。各サービスの設定・規約・プライバシーポリシーが適用されます。認証用の秘密情報はクラウド環境のネットワークシークレットとして保存し、アクセス先をGoogleの認証エンドポイントに限定します。

共有

広告や販売のためにDriveのデータを利用しません。所有者の指示がない限り、Driveファイルの公開・第三者への共有を行いません。この公開サイトに認証情報やDriveファイルの内容を保存しません。

取り消しと削除

所有者はGoogleアカウントの接続設定からアクセス許可を取り消せます。クラウド環境の秘密情報や作業履歴、Google Driveの成果物は、それぞれのサービスで管理・削除してください。アクセス取消しだけで保存済み成果物や履歴が自動削除されるとは限りません。

本アプリによるGoogle APIから受領した情報の利用・移転は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

管理者・問い合わせ先: GitHub Issues（秘密情報は投稿しないでください）
